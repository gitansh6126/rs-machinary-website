Deployment Checklist

  1. Google Sheet — Create a Google Sheet with ID set in Code.gs (line 14: SPREADSHEET_ID).
  2. Apps Script — Deploy apps-script/Code.gs as a Web App (Execute as: Me, Who can access: Anyone).
  3. API URL — Copy the deployed Web App URL and paste it above.
  4. Public Site URL — Update website/js/api.js line 15: BASE_URL with the same Web App URL.
  5. Hostinger — Upload website/ folder to public_html and admin/ folder to admin subdomain.
  6. First Login — Visit admin.yourdomain.com, enter any password. It will be saved as your admin password.
